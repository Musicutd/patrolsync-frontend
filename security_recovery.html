Company Data Export

Download a portable JSON copy of your company configuration and core operational records. Password hashes and API secrets are excluded.

Database Backup & Restore

Company exports are useful for portability, but they are not a replacement for a PostgreSQL backup. Database snapshots and point-in-time restoration must be configured and tested through your database hosting provider.

Recommended: confirm automatic backups are enabled, record the retention period, and test a restore into a separate database before launching commercially.
