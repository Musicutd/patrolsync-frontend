Deployment Behaviour

  • Readiness becomes false before shutdown begins.
  • New requests receive HTTP 503 with a retry hint while draining.
  • Existing requests are allowed to finish for up to 25 seconds.
  • Recurring job timers stop before database connections close.
  • System and restricted tenant pools close cleanly.
  • Database advisory locks prevent duplicate jobs across instances.
